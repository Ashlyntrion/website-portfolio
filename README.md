# Website Build — Leadership Coaching & Training Practice

A complete multi-page marketing website and a matching custom WordPress theme,
designed and built end to end as freelance client work.

**Role:** design + front-end build + WordPress theming
**Status:** delivered to the client and in use

## What was built

**Static marketing site — 7 pages**
Home, About, Services (coaching), Corporate Training, Gallery, Testimonials, Contact.

**Custom WordPress theme**
Hand-written PHP templates mirroring the static site (`front-page`, per-page
templates, shared header/footer, theme functions), packaged as an installable
theme with a stylesheet header and screenshot.

## Notable front-end work

- Sticky header with a scroll-triggered shadow state
- Responsive navigation with an accessible (ARIA) mobile toggle and Services dropdown
- Scroll-reveal animations via `IntersectionObserver`
- Animated statistic counters that ease out and only fire when scrolled into view
- Custom gallery lightbox with prev/next, click-outside and keyboard controls (←/→/Esc)
- Contact form with client-side validation feedback
- Hand-written CSS with a print-style typographic system (variable serif + geometric
  sans + script accent via Google Fonts), no CSS framework
- Vanilla JavaScript only — no dependencies or build step

## Stack

`HTML5` · `CSS3` · `vanilla JavaScript` · `WordPress theme (PHP)` · `Google Fonts`
